# GAZE — Конструктор систем видеонаблюдения (TWA)

Профессиональное приложение для расчета и заказа систем видеонаблюдения, работающее как Telegram Web App.

## Основные возможности

- **Умный калькулятор:** Автоматический подбор оборудования на основе площади и типа объекта.
- **Безопасность:** Backend-first архитектура с валидацией Telegram `initData` на стороне сервера.
- **Интеграция с Картами:** Выбор адреса через Яндекс.Карты с точностью до здания.
- **Админ-панель:** Управление ценами в реальном времени, просмотр заказов и логов.
- **VIP-система:** Автоматические скидки и расширенные функции для постоянных клиентов (от 3 заказов).
- **Поддержка:** Встроенный чат поддержки (активируется после заказа).
- **Отказоустойчивость:** Дублирование заявок на Email через SMTP при сбоях API.

## Технический стек

- **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JS, Anime.js (анимации), Yandex Maps API.
- **Backend:** Node.js, Express.
- **Database:** MySQL (поддерживается на Railway.app) / SQLite (для локальной разработки).
- **Auth:** HMAC-SHA256 валидация данных Telegram.

## Установка и запуск

### Требования
- Node.js 18+
- Telegram Bot Token (от @BotFather)

### Локальный запуск
1. Клонируйте репозиторий.
2. Создайте файл `server/.env` на основе примера:
   ```env
   BOT_TOKEN=your_telelgam_bot_token
   ADMIN_IDS=12345678,87654321
   APP_URL=https://your-app-url.com
   SMTP_HOST=smtp.example.com
   SMTP_PORT=587
   SMTP_USER=user@example.com
   SMTP_PASS=password
   ```
3. Установите зависимости и запустите сервер:
   ```bash
   cd server
   npm install
   node index.js
   ```

## Развертывание на Railway.app

Приложение полностью готово к деплою на Railway с использованием MySQL:
1. Подключите репозиторий к Railway.
2. Добавьте переменные окружения из `.env`.
3. Railway автоматически предоставит переменные `MYSQLHOST`, `MYSQLUSER` и т.д., которые сервер использует для подключения к БД.

## Структура проекта

- `/server` — Backend (API, БД, интеграции).
- `/app.js` — Основная логика фронтенда и анимации.
- `/index.html` — Разметка и UI компоненты.
- `/main.css` — Стилизация и Glassmorphism эффекты.
- `storage.js` — Слой взаимодействия с API сервера.
